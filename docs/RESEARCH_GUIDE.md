# 研究工作台使用指南（v0.3）

使用 `/crew/` 镜像时访问 [本地工作台](http://127.0.0.1:8765/crew/)（HTTP 调试设置 `COOKIE_SECURE=false`）；首次创建管理员，之后登录并进入左侧「公司研究中心」。正式入口为 `https://tec.zhiquant.com/crew/`。

## 第一次使用

1. 在「研究工作台」建立公司档案。一个档案对应一家公司；同一家公司的港股/美股证券可以放在一起。不同公司应分别建档，然后用「行业与竞对」建立比较组。
2. 在「连接设置」保存并测试 DeepSeek、长桥。已有配置在升级后保留。
3. 选择公司，发起「最新数据 + AI 研究」，或在「财报与电话会」点击「采集最新资料并整理」。运行结束后点击「刷新档案」。
4. 核对报告和自动提取的记录，填写理由后确认。报告确认更新投资逻辑；指标/承诺/披露记录需要分别核对，不因报告被接受而自动批准全部提取。

## 长期档案与投资逻辑

「长期档案」显示历次研究、资料导入、承诺、指标、审阅、决策和复盘。搜索框可搜索内容或 ID。当前逻辑只取自你确认的报告；每次确认保留变化前、变化后、原因和当次证据。不同于新建研究草稿，确认操作会更新当前公司逻辑。

「导出完整公司档案」下载 JSON，包含记录和证据哈希/引用。原始证据文件仍在 Docker 数据卷，可通过「证据档案」逐条查看。JSON 导出不是整个数据卷的备份。

## 财报、电话会及来源

自动研究会查长桥的财务三表、财报概览、新闻与公告，并尝试发现相关正文。电话会全文、节选和媒体摘要有明确标识；无问答原文时不会把推测填成管理层回答。

有逐字稿时，点击「导入财报 / 电话会原文」，填写标题、来源链接、已知发布日期，并粘贴或读取文本文件。保存后可立即让 DeepSeek 整理，或只保存后再点「重新整理原文」。用户导入的内容始终保留未经独立核验的来源标记。

粘贴原文最大 20 万字符。PDF、扫描件、图片及 Office 文件可以使用「文件与图片」入口（见下文）。音频仍需先转写成文本。提示词中长材料会截断预览，Agent 可分页读取；输出的缺口需一并检查。

## 管理层承诺

AI 从资料中提取，也可以手动登记：承诺内容、发言人、提出日期、截止日、适用条件和来源原句。量化承诺另填指标、目标、至少/至多/等于、对应期间、币种、单位和会计口径。

核对确认后，系统查找已确认的同口径实际指标，显示数值是否达到目标。最终评价需核查承诺条件：点击「对照实际结果评价」，选择实际指标或作定性评价，并说明依据。每次评价单独保存，延期、部分兑现和待验证也可记录，不覆盖以前的判断。

## 预期、指引和实际

「预期与指引」支持 actual / consensus / guidance / industry 四类指标。填原始单位，避免把百万美元与美元或 GAAP 与 non-GAAP 混用。AI 无法从原文明确取得关键字段时会留缺口，人工可核对原始披露后补充记录。

「比较两条指标」可比较旧指引→新指引、旧一致预期→新一致预期，或预期→实际。预期差要求旧预期已在结果公布前记录；事后补填的预期不能冒充历史预测。零基数不计算百分比。

长桥一致预期表可切换财务期间，查看供应商返回的实际/预期/差额。该接口缺少预测形成时间的部分明确标注，不能用它证明系统提前预测成功。

## 行业与竞争对手

先分别建立 2–6 家公司档案，创建行业/竞对组并写清比較目的。进入组后可「整组采集与研究」，队列会逐家处理。已保存的同行证据提供给后续组内研究，并保留采集时间，不能视作同时点数据。

比较表只对齐已确认的相同指标、日历期间、单位、币种和会计口径。缺少同口径资料的公司显示缺口，不填零、不强行排名。长桥行业营收排名作为原始行业证据保留，可点击查看。

需要持续跟踪时，在左侧「持续跟踪」为成员证券建立并启用间隔计划；选择「研究」会同时整理新增记录。计划只在容器运行期间执行。

## 投资决策与复盘

「记录一次投资决策」填写行动、当时理由、替代方案、风险，并逐项填写原始假设、失效条件、检查日期和计划复盘日。系统冻结当时的投资逻辑与证据哈希，不执行交易。

历史补记要选择「事后补记」；系统标出哪些证据在决定之后才入库，不能把事后资料说成当时已知。不能记录未来已发生的决策。

到复盘时打开原始决策，点击「逐项复盘这次决策」，逐一评价原假设得到支持、被证伪或尚待验证。分别写实际结果、过程质量、教训和改进，引用观察证据。允许多次复盘，各版保留。也可以点「让 AI 检查最新证据」，生成独立研究报告供核对；AI 不会改写原始决策。

## 日常维护

```bash
cd /Users/brown/program/www/crew-stock
docker compose ps
docker compose logs --tail=50 app
docker compose restart
```

使用 `docker stop crew-agent` 停止应用。业务记录和账号在 MySQL，原始文件及模型配置在 `/data` 卷，长桥授权使用独立卷；备份时三者都要保留。详见 README 的构建、启动和旧数据迁移步骤。


## v0.3：独立行业与持续观察

左侧「行业研究中心」→「建立行业」。例如创建“存储行业”，先在研究工作台分别建立美光、SK 海力士、闪迪的公司档案，再勾选成员并填写 DRAM、HBM、NAND 等研究角色。**行业不是一家公司**；已有公司档案保持独立，一家公司可以属于多个行业。旧的行业/竞对比较组继续保留，不会自动迁移或复制。

- 填写行业范围和持续观察重点，如价格、库存、供需、产能、技术路线。
- 「整行业采集与研究」会按当前成员快照逐家公司调用原有长桥 + CrewAI 研究流程，最后由 DeepSeek 综合行业报告。最多 30 家成员；成员失败、不同采集时点、资料截断都会留下记录。行业汇总使用成员报告摘要和最多 80 份证据的前 700 字，不能替代全文审阅。
- 「设置行业跟踪计划」可配置 1–720 小时间隔，支持只采集或研究并汇总；默认暂停，选择启用后在容器运行期间执行。已有行业批次未结束时不重复调度。成员变化只影响后续批次。
- 行业报告保存摘要、分类结论、证据引用、与上期变化、反方证据和资料缺口，当前均作为待核查的 AI 建议。确认公司报告不会自动确认行业判断。
- 每家公司卡片可回到独立档案，原公司中心内的竞对比较表继续负责同口径指标比较。

## v0.3：文件与图片解析

左侧「文件与图片」→「上传并解析」。v0.4 起默认独立上传、解析后 AI 归类；也可以先选公司/行业再上传，或从公司财报页、行业详情进入。

支持：PDF（包含扫描页）、JPEG/PNG/WebP/静态 GIF、DOCX、XLSX、UTF-8 TXT/Markdown/CSV/JSON。旧版 DOC/XLS、动态图、音视频暂不支持。

- 图片/PDF 需要 `deepseek-flash`，使用真实多模态接口。PDF 逐页提取文字并渲染图片，让模型读取图表及扫描内容；原 PDF 不会直接当作文本附件发送。
- 每文件最多 12 MiB；PDF 默认前 10 页，可选择连续最多 20 页。页面没全部解析时显示“仅选定页，非全文”，可分批上传不同页段。
- DOCX 提取正文及表格文字，不包含嵌图和页眉页脚。XLSX 最多 20 个工作表，每表 1000 行、50 列；公式保留但不执行，不读取嵌图。Office 嵌图请单独上传。
- 原件保存为内容哈希文件；本地提取文字、AI 转录/摘要、不确定项分别保存，并关联页码或工作表及证据 ID。模型识别是未经核实的用户资料，不会自动升级为公司事实。
- 所选范围的图片或文档文字会发送至已配置的 DeepSeek，并产生模型费用。公司资料解析完成后，可点击「基于解析资料发起公司研究」；行业资料进入后续行业汇总的证据范围。
- 中途失败保留原件和已解析页面，可重试；容器重启中断会明确标记，不能冒充已完成。

## v0.3：供应链影响图与冲击情景

原设计中的“发散图/拓扑图”对应有向加权供应链影响图。左侧「供应链影响图」或公司/行业详情均可进入。

1. 选择公司或行业范围及关联层数；可以拖动节点、缩放、查看直接一级或多级关系。
2. 用「登记关系」记录影响来源、受影响对象、供应品类、日期、证据原句、置信度和六项风险评分。也可以用「从证据提取关系」选择最多 15 份已保存资料，由 DeepSeek 提出候选。
3. 点击关系查看证据、评分依据及版本历史，再确认或驳回。AI 候选显示为虚线；无证据不会虚构供应链。更改关系会新建版本，重新等待审核，旧版本保留。
4. 点击节点选择冲击源，打开「设置冲击情景」。填写冲击幅度、时间范围、时间因子、阻尼、缓冲比例和最大传导层数，并记录假设。
5. 计算后展示节点情景暴露、高亮受影响路径，并保存参数、关系版本和路径结果。只有人工确认的关系参与计算；灰色行业成员线仅表示归属，不参与传导。

六项权重为关键性 25%、难以替代程度 20%、集中度 20%、缓冲不足 15%、经济暴露 10%、地缘风险 10%。各项由人或模型评分，**权重不是客观事实，置信度也不是发生概率**。

传导采用 `上游冲击 × 依赖权重 × 置信度 × 时间因子 × 阻尼 × (1 − 缓冲)`，多路径有界合并，不超过冲击源幅度；同一路径不重复经过节点，循环被截断。最大深度 6、最大路径数 5000。时间范围与传导因子由用户设定，尚未用经济数据校准；共享路径可能造成重复影响。**结果只是运营依赖情景估算，不是股价、收入变化或收益率预测。**

现有数据没有已登记关系时，图中只显示公司/行业节点和成员线。这代表缺少关系证据，不是系统已自动识别出“无依赖”。公众人物、舆情传播的独立图通道仍未实现。


## v0.4：独立识别与多档案归类

1. 在「文件与图片」保持「全部资料 · 上传后自动识别归类」，直接上传资料，无需先选公司。
2. 后台先完成页面/工作表解析，再识别财务报告、电话会、研究报告、新闻、行业数据或其他资料，以及主题标签、公司和行业候选。
3. 卡片显示实际关联、分类状态、正文引用、匹配原因、置信度和覆盖范围。分类只使用每页/表已解析文字的前 5000 字，不代表阅读未选范围或完整长文。
4. 自动关联要求：已存在的档案、置信度至少 0.9、逐字引用可回溯且包含已有唯一名称/证券代码。模型置信度不是校准过的概率；AI 转录也可能有误，仍须核对原件。
5. 点击「核对 / 调整归属」勾选一个或多个公司/行业。原件和证据不复制，档案通过关联表共享。后续 AI 重识别不会覆盖人工归属。预先明确指定的原档案会保留，可以增加其他关联；独立上传的关联可以移除。
6. 没有档案的公司/行业只列为候选；先到相应中心创建，再回来关联。不会因模糊简称自动创建证券或把不同公司合并。
7. 点击「基于此资料研究 · 公司名」进入已有研究流程。归类失败不会丢失解析结果，可重新识别或手动归档。

## v0.4：股价判断、开仓方案与模拟账户

### 从研究到价格

打开「决策与模拟」，选择公司→「生成开仓方案」→选择该公司的证券并填写决策问题。程序读取公司档案、行业研究、供应关系与冲击假设，并重新采集长桥行情和估值资料，由 CrewAI 的 DeepSeek LLM 适配器生成结构化方案。

方案说明：经营/行业变化如何影响每股盈利、估值倍数为何成立、市场已经反映哪些预期、催化剂、反方证据、逻辑失效条件、持有观察期及数据缺口。三种情景使用明确标为假设的 **未来 EPS × PE**，乘法由程序执行。图谱传导百分比不会直接换算成股价涨跌幅。

该版本只实现 PE 情景估值。负盈利、行业不适用或证据不足时，模型应给出「继续观察 / 暂时回避」，不强行补造 EPS。只有具有完整价格条件的「满足条件可模拟买入」方案才能进入开仓表单；程序要求止损 < 买入区间 < 止盈、收益风险比至少 2、止盈不高于基准估值。方案 7 天后不能再用于新开仓。估值结论不是收益保证。

### 建立和执行模拟决定

1. 点击「新建模拟账户」，填写名称、币种、初始虚拟资金、费用基点和不利滑点。默认费用与滑点各 5 基点，即 0.05%；这是测试假设，不是券商费率。
2. 在方案上点击「测算仓位 / 模拟开仓」。选择同币种账户、买入限价、计划风险占权益比例（默认 1%，上限 5%）、单笔资金占权益上限（默认 10%，上限 50%）。
3. 点击「测算可买数量」。程序同时受可用现金、单笔资金比例、计划止损损失预算和每手股数约束。费用及假设的止损退出滑点计入风险测算；价格跳空仍可能突破预算。可以调低股数，不能绕过服务端上限。
4. 审核假设与失效条件并勾选确认，提交**本地模拟限价委托**。此时只预留现金，状态是「待成交」，没有真实券商订单。
5. 点击账户「获取行情并模拟撮合」，或显式启用「每分钟跟踪」。这只是后台检查的目标间隔，共享研究队列繁忙时会延迟；停止容器后不执行。行情来源仍是长桥只读接口。
6. 查看待成交、部分成交、已模拟成交、已撤销或已过期。未完成的买入委托可以撤销剩余部分，已经模拟成交的持仓保留。平仓按钮提交本地模拟市价退出，等待下一次有效行情。
7. 「决策与复盘档案」自动留存决定时的方案、证据哈希和预算。点击「记录复盘」，填写哪些证据改变逻辑、过程是否合理、下一步行动；每次复盘保留当时的委托和账户状态，不覆盖原决定。

### 模拟撮合的具体假设

- 仅现金多头、整手买入/退出；不做空、不融资、不交易期权、不换汇，不实现加仓。同一账户同一证券最多一个活跃委托方向，最多 30 个活跃证券。
- 使用长桥最新**成交快照**，而非可执行盘口。价格必须带交易时间、证券处于正常状态、快照在 120 秒内且严格晚于委托创建时间；过旧、停牌、缺时间、币种不符或失败时不会模拟成交。
- 买入在加上不利滑点后仍不超过限价且高于方案止损时，按快照成交量上限模拟；同一账户同一证券的同一时间戳成交量不重复使用。只取最新一笔，可能错过中间成交或低估成交机会，不代表真实市场排队。
- 已持仓证券触及止损/止盈时创建退出委托，用后续新快照模拟卖出，不回填成已经在触发价成交。刷新间隔、跳空和滑点可能扩大损失。
- 限价与方案同到期；即使没有新行情也会释放过期未成交部分的资金。手动平仓委托有效 7 天。已成交持仓不会因原开仓方案过期而消失。
- 费用、持仓成本与盈亏由 Decimal 账本计算；权益是最近标记价估算，标记时间显示在持仓旁。各账户独立，不共享虚拟流动性。
- 未模拟交易所撮合队列、完整交易日历、结算限制、停复牌细则、税制、分红拆股和公司行动；延长交易时段快照也可能参与。**不是实盘回测或券商纸交易账户，模拟收益不能当作已验证策略收益。**

当前没有真实开仓/撤单 API，也没有将长桥账户资金接入此页面；后续实盘是单独的实现范围。

## v0.5：供应链订单

新增“供应链订单”入口。上传资料后点击“识别订单与履约变化”，核对候选中的交易方、金额、交付/付款节点与引用，确认后显示货物流和合同货款流。订单可关联未上市企业，并单独启用周期观察；AI 发现变化后仍须审核。

订单确认后进入公司档案和决策方案的证据上下文。订单金额、收入确认、现金回收分别判断；到期未见披露只提示核查。详细操作、模糊期限处理、历史回放与监控边界见 [供应链订单使用指南](ORDER_GUIDE.md)。
