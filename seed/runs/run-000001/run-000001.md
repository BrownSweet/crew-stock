## 4. 数据处理链

1. MCP 完整响应保存为 `<evidence_id>.json`。
2. 对每份 JSON 计算 SHA-256，写入同目录 `<evidence_id>.yaml`。
3. 元数据分别记录 `source: longbridge`、`transport: mcp|cli`、实际工具、完整参数、采集状态和业务截止时间。
4. 行情和估值归属 `sec-000001`；公司概况、合并财报、业务分部、机构预期、新闻和文件归属 `cmp-000001`。
5. 结构化报告只引用证据 ID，不复制或覆盖原始响应。
6. 外部机构评级保留为 `opinion`；模型推断保持 `pending_confirmation`，不自动形成投资结论。
