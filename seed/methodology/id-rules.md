# ID 编号规则表

> 规则版本：`1.1`  
> 生效日期：2026-08-03  
> 适用范围：公司、证券、行业、公众人物、观点、用户提交、证据、研究文档、事件、承诺、决策、报告、冲击情景和定时任务等可独立引用对象

## 1. 标准格式

ID 统一使用：

```text
<type_prefix>-<sequence>
```

例如：

```text
cmp-000001
sec-000001
ind-000001
evd-000001
```

校验正则：

```regex
^[a-z]{3}-[0-9]{6}$
```

规则：

- 类型前缀固定为 3 位小写英文字母；
- 序号固定为 6 位十进制数字，不足时左侧补零；
- 每种类型拥有独立序列，从 `000001` 开始；
- ID 中不写入日期、市场、证券代码、公司名或行业名；
- 业务属性保存在元数据中，避免因名称、日期或归类改变而修改 ID。

## 2. 类型前缀规则表

| 前缀 | 对象类型 | 中文名称 | 典型父对象 | 示例 | 说明 |
| --- | --- | --- | --- | --- | --- |
| `cmp` | company | 公司主体 | 无 | `cmp-000001` | 实际经营、合并报表和信息披露主体 |
| `sec` | security | 可交易证券 | `cmp` | `sec-000001` | 某公司发行的具体证券，一个代码不等于一家公司 |
| `ind` | industry | 行业 | 无 | `ind-000001` | 跨公司的产业链、供需和竞争格局研究对象 |
| `per` | person | 公众人物 | 无 | `per-000001` | 与公司、行业、政策或市场叙事相关的公开人物 |
| `opn` | opinion | 人物观点 | `per` | `opn-000001` | 人物的可引用解读、预测、事实声称或价值判断 |
| `sub` | submission | 用户提交 | 无 | `sub-000001` | 用户上传文件、链接、观点转述或主观批注的原始提交 |
| `rel` | relation | 关系 | `cmp` / `ind` / `per` | `rel-000001` | 供应、需求、任职、评论和叙事影响等对象间关系 |
| `doc` | document | 研究文档 | `cmp` / `ind` / `sec` / `per` | `doc-000001` | 公司画像、投资逻辑、产业链、人物档案等可版本化文档 |
| `evd` | evidence | 原始证据 | `cmp` / `ind` / `sec` / `per` / `sub` | `evd-000001` | 财报、监管文件、新闻、社交媒体内容、用户上传或其他原始来源 |
| `evt` | event | 时间线事件 | `cmp` / `ind` / `sec` / `per` | `evt-000001` | 能够独立引用的历史或待发生事件 |
| `prm` | promise | 管理层承诺 | `cmp` | `prm-000001` | 具有原始表述、验证指标、目标时间和状态历史的承诺 |
| `exp` | expectation | 预期或指引记录 | `cmp` / `sec` | `exp-000001` | 公司指引、一致预期或对应变化记录 |
| `met` | metric | 指标 | `cmp` / `ind` / `sec` | `met-000001` | 需要长期跟踪的公司或行业指标定义 |
| `dec` | decision | 用户决策记录 | `cmp` / `sec` / `ind` | `dec-000001` | 由用户确认的决策、当时信息和后续复盘 |
| `rpt` | report | 定期或事件报告 | 多对象 | `rpt-000001` | 日报、周报、月报、季报深度研究或专项报告 |
| `sim` | simulation | 冲击传导情景 | `cmp` / `ind` / `evt` | `sim-000001` | 一次可复现的供应链或行业冲击传导模拟 |
| `run` | run | 定时任务运行 | 任务 | `run-000001` | 一次完整的采集、分析或报告运行记录 |
| `sta` | state | 状态快照 | 任意研究对象 | `sta-000001` | 去重水位、最近采集位置和可恢复状态 |
| `tpl` | template | 模板 | 模板类型 | `tpl-000001` | 可复用的公司、证券、行业或公共内容模板 |
| `att` | attachment | 附件 | `evd` / `doc` / `sub` | `att-000001` | 一条证据、文档或用户提交下需要独立保存的附件 |

## 3. ID 文件夹命名

每个可独立引用的最小对象必须是一个与 ID 同名的文件夹。

```text
<id>/
├── <id>.yaml
└── <id>.<payload_extension>
```

示例：

```text
companies/
└── cmp-000001/
    ├── cmp-000001.yaml
    ├── securities/
    │   ├── sec-000001/
    │   │   └── sec-000001.yaml
    │   └── sec-000002/
    │       └── sec-000002.yaml
    └── evidence/
        └── filings/
            └── evd-000001/
                ├── evd-000001.yaml
                └── evd-000001.md
```

如果一个对象需要多个独立附件，每个附件再使用独立 `att` ID 文件夹：

```text
evd-000001/
├── evd-000001.yaml
└── attachments/
    ├── att-000001/
    │   └── att-000001.pdf
    └── att-000002/
        └── att-000002.html
```

## 4. 序号分配规则

1. 各类型独立递增，例如 `cmp` 和 `sec` 都可以从 `000001` 开始。
2. 创建时取该类型的下一个可用序号。
3. 序号不表示排名、重要性、创建日期或上下级关系。
4. ID 分配后立即登记，即使对象后续创建失败，该 ID 也不再重用。
5. 对象停用时将状态改为 `archived` 或 `void`，不删除编号记录。
6. 定时任务并发创建 ID 时，必须通过唯一分配器和文件锁避免重号。
7. 定时任务不得根据目录数量自行猜测下一个 ID。

## 5. ID 登记表

实现阶段维护一张中央 ID 登记表，至少包含：

| 字段 | 必填 | 说明 |
| --- | --- | --- |
| `id` | 是 | 对象的永久 ID |
| `type` | 是 | 对象类型 |
| `parent_id` | 否 | 直接父对象 ID |
| `display_name` | 是 | 人类可读名称 |
| `status` | 是 | `active`、`archived` 或 `void` |
| `created_at` | 是 | ID 创建时间，使用 ISO 8601 |
| `path` | 是 | 当前文件夹相对路径 |
| `aliases` | 否 | 证券代码、旧名、中英文名等可变别名 |
| `notes` | 否 | 分配、停用或迁移说明 |

建议实现文件：

```text
registry/
├── id-registry.csv
└── id-sequences.yaml
```

`id-registry.csv` 是 ID 与对象路径的唯一登记表；`id-sequences.yaml` 保存各前缀下一个可分配序号。

## 6. 元数据最小字段

每个 `<id>.yaml` 至少包含：

```yaml
id: evd-000001
type: evidence
parent_id: cmp-000001
display_name: 2026 Q2 regulatory filing
status: active
created_at: 2026-08-03T10:00:00+08:00
updated_at: 2026-08-03T10:00:00+08:00
```

## 7. 禁止规则

- 禁止使用公司名、人名、中文拼音或证券代码代替永久 ID；
- 禁止修改已分配 ID 的数字部分；
- 禁止复用已停用或创建失败的 ID；
- 禁止在未登记的情况下由定时任务直接创建 ID 目录；
- 禁止用 ID 编号大小表示投资优先级或公司重要性；
- 禁止因为证券换代码、公司改名或行业调整而更换既有 ID。

## 8. 例外

以下是仓库级控制文件，不属于研究对象，可以使用固定语义文件名：

- `AGENTS.md`；
- `关键设计.md`；
- `universe.yaml`；
- `methodology/` 下的规则文件；
- `registry/id-registry.csv`；
- `registry/id-sequences.yaml`。

除上述控制文件外，可独立引用的研究对象均必须使用 ID 文件夹。
