# 数据来源与分析职责规则

> 规则版本：`1.0`  
> 生效日期：2026-08-05  
> 适用范围：Longbridge MCP、Longbridge CLI、Codex Scheduled task、本地确定性程序和 LLM 研究分析

## 1. 核心原则

研究流程分为三层：

```text
Longbridge / 用户上传：获取原始事实和原始内容
                     ↓
确定性程序：编号、哈希、去重、差异、数值计算和状态管理
                     ↓
LLM：语义抽取、分类、解释、关系识别和待确认研究判断
```

禁止用 LLM 重新发明 Longbridge 已返回的数字，也禁止将 Longbridge 的机构观点、社区讨论或市场情绪直接当作系统结论。

## 2. 数据来源优先级

1. 上市公司、证券、行情、财务、估值、预期、新闻和监管文件：优先 Longbridge。
2. 用户主动提供的公开内容、社交媒体内容、截图、转写和个人批注：使用 `sub-*` 保存。
3. Longbridge 不覆盖的未上市公司、完整供应链、公众人物原始言论和电话会全文：标记为缺口，通过用户上传或已授权公开来源补充。
4. 禁止在 Longbridge 查询失败后静默使用未标注来源的替代数据。

## 3. 数据与分析职责矩阵

| 研究内容 | Longbridge | 确定性程序 | LLM |
| --- | --- | --- | --- |
| 证券身份、名称、市场、流通股 | 直接获取 | 映射 `cmp-*` 和 `sec-*` | 识别同公司多证券关系 |
| 公司简介、成立时间、员工 | 直接获取 | 快照和字段变更对比 | 整理稳定公司画像 |
| 高管与董事 | 直接获取 | 对比任职变化 | 分析管理层稳定性及关键人物变化 |
| 财务三表 | 直接获取 | 同比、环比、利润率和现金流计算 | 解释变化原因和质量 |
| 业务分部 | 直接或按市场部分获取 | 计算占比和趋势 | 判断增长驱动与业务结构变化 |
| 运营指标 | 部分市场可获取 | 历史趋势计算 | 判断经营拐点 |
| EPS 预测、一致预期 | 直接获取 | 记录上调、下调和变化幅度 | 分析预期差 |
| 机构评级和目标价 | 直接获取 | 统计评级分布变化 | 分析机构分歧，不直接采信 |
| 估值、历史估值、行业排名 | 直接获取 | 分位数和可比公司计算 | 解释估值变化及其前提 |
| 监管文件列表 | MCP 和 CLI 可获取 | 文件去重和 ID 分配 | 选择需要深读的文件 |
| 监管文件全文 | CLI `filing detail` 更适合 | 原文、哈希和路径保存 | 抽取承诺、风险、指引和变化 |
| 新闻列表和摘要 | MCP 和 CLI 可获取 | 去重、时间线和相关证券关联 | 识别催化剂及事实/推测 |
| 新闻全文 | CLI `news detail` 或 Longbridge Markdown | 原文归档 | 摘要、观点和影响判断 |
| 投资者关系记录 | 按市场部分获取 | 整理时间线 | 判断管理层沟通变化 |
| 股东、基金持仓 | 直接获取 | 计算持仓变化 | 分析机构行为及局限 |
| 内部人交易、13F | CLI 能力更完整 | 计算数量和时间变化 | 判断行为背景，避免过度推断 |
| 做空持仓和做空成交 | 直接获取 | 比率、趋势和覆盖天数 | 分析空头压力是否异常 |
| 行业排名和行业层级 | 获取 Longbridge 分类 | 映射本地 `ind-*` | 建立本地自定义行业边界 |
| 宏观数据和财经日历 | 直接获取 | 同比、环比和发布时间匹配 | 判断宏观变量的影响路径 |
| 行情、K 线、成交和资金流 | 直接获取 | 指标计算和异常检测 | 结合事件解释价格行为 |
| 供应链和上下游 | 通过财报、新闻等提供间接证据 | 关系去重和图传导计算 | 抽取关系并提出有证据的模型权重 |
| 未上市公司 | 不能依赖证券代码完整获取 | 保存用户资料 | 整理并交叉验证 |
| 公众人物和社交媒体观点 | 新闻或社区可能部分覆盖 | 保存用户上传原文和哈希 | 身份解析、观点抽取、立场和影响分析 |
| 用户主观批注 | 不提供 | 本地保存 | 标记为 `user_annotation`，不冒充原文 |
| 投资逻辑和决策复盘 | 不提供 | 保存历史版本 | 发现冲突并提出待确认变更 |

## 4. LLM 允许与禁止职责

### 4.1 LLM 允许

- 从财报、监管文件、新闻和上传内容中抽取结构化信息；
- 抽取管理层承诺、公司指引和可验证条件；
- 区分事实、推测、市场情绪、外部观点和用户批注；
- 识别新闻和事件影响的业务通道；
- 抽取供应链、客户、竞争、任职、评论和叙事影响关系；
- 按已确认评分表提出供应链权重和人物影响力权重；
- 发现原有投资逻辑与新证据的冲突；
- 生成待用户确认的研究结论、反方证据和复盘问题。

### 4.2 LLM 禁止

- 分配或猜测下一个 ID；
- 代替确定性程序计算同比、环比、收益率和估值分位；
- 负责文件哈希、去重和采集水位；
- 在没有来源时猜测供应链关系；
- 将人物影响力当作观点正确性；
- 静默修改公司事实、用户决策或已确认投资逻辑；
- 在 Longbridge 失败时用模型记忆伪造当前数据。

## 5. Longbridge skill 的位置

`longbridge:longbridge` skill 是 Codex 使用 Longbridge 的工作说明和能力路由，不是数据库，也不代替 MCP 或 CLI。

定时任务提示词应显式要求使用 `$longbridge:longbridge`，并在专项分析中路由到：

| 环节 | 专项 skill |
| --- | --- |
| 行情、K 线、资金流 | `longbridge:longbridge-market-data` |
| 财务、业务分部、估值 | `longbridge:longbridge-fundamentals` |
| 机构评级、一致预期、股东和内部人 | `longbridge:longbridge-research` |
| 新闻、监管文件和社区内容 | `longbridge:longbridge-content` |
| 行业排名、异动和市场情报 | `longbridge:longbridge-intel` |
| 财报前后研究 | `longbridge:longbridge-earnings` |

skill 负责选择正确能力；MCP 或 CLI 负责返回数据；本地仓库负责长期保存。

## 6. MCP 与 CLI 分工

| 场景 | 首选 |
| --- | --- |
| 互动问答和临时研究 | MCP |
| Codex 根据问题动态组合多个查询 | MCP |
| 试点阶段 | 已验证可调用的 MCP |
| 大批量公司定时采集 | CLI |
| 监管文件和新闻全文归档 | CLI |
| 可复制的 JSON 命令和运行日志 | CLI |
| 本地脚本、断点续跑和批量处理 | CLI |
| 已授权传输失败后的只读备用路径 | 仅允许一次受控回退 |
| 任何金融写操作 | 禁止 |

MCP 和 CLI 必须进入同一标准化适配层，但原始数据不得混合或覆盖。

## 7. 原始采集信封

每次 MCP 或 CLI 采集必须保存：

```yaml
provider: longbridge
transport: mcp
operation: longbridge_financial_report
arguments:
  symbol: AAPL.US
  kind: ALL
captured_at: 2026-08-05T09:00:00+08:00
adapter_version: 1
raw_path: companies/cmp-000001/evidence/financials/evd-000001/
content_hash: <sha256>
status: success
error: null
```

必填内容：

- 提供方和传输方式；
- MCP 工具名或 CLI 命令；
- 完整参数；
- 采集时间；
- 目标证券或研究对象；
- 原始响应；
- 内容哈希；
- 适配器版本；
- 运行状态和错误。

## 8. 受控回退

1. 仅允许只读查询在明确网络、授权或服务不可用时回退。
2. 每次采集最多从首选传输回退到另一个已授权传输一次。
3. 回退后保留首次失败和第二次运行记录。
4. 因 MCP 与 CLI 返回 schema 可能不同，两份原始响应分开保存，只在标准化层合并。
5. 不对订单、提醒、自选、社区发布或其他写操作进行回退或重试。

## 9. 当前验证基线

以 2026-08-05 当前工作区为准：

- `longbridge:longbridge` skill 已安装；
- Longbridge plugin/MCP 已暴露工具；
- MCP `now`、`static_info` 和 `company` 已实际调用成功；
- Longbridge CLI 已安装，版本为 `0.26.0`；
- CLI OAuth 当前为 `not_found`；
- CLI 当前工作区网络和日志写入未验证可用；
- skill 示例中的 `analyst-estimates` 不存在于当前 CLI，应使用 `forecast-eps` 和 `consensus`；
- CLI、MCP 和 plugin/skill 的安装、授权和实际可调用状态必须分开报告。

上述属于易变运行状态，每次实施或启用定时任务前必须重新验证。

## 10. 定时采集流程

```text
1. Scheduled task 启动
2. 显式使用 $longbridge:longbridge
3. 检查目标公司、证券和研究对象 ID
4. 从只读白名单选择 MCP 工具或 CLI 命令
5. 原始响应写入 evd-* 文件夹
6. 确定性程序完成哈希、去重、差异和数值计算
7. LLM 只读取新增或发生变化的证据
8. LLM 抽取承诺、观点、关系和实质变化
9. 重要判断写入待确认区，不直接覆盖已确认逻辑
10. 生成 run-* 运行记录
```

## 11. 能力缺口处理

- Longbridge 不能被假定为完整供应链数据库；
- Longbridge 新闻和社区内容不能被假定为完整社交媒体数据源；
- 电话会全文、未上市公司、公众人物原帖和供应商/客户关系需按实际市场和对象验证可获得性；
- 缺失数据必须记录为 `missing`、`unsupported` 或 `not_authorized`，不得生成伪数据。
