# opn-000001：AI 光互连价值由 Scale-out 向 Scale-up 迁移

## 核心观点

AI 数据中心继续扩张，但下一阶段的关键瓶颈可能从“连接更多服务器和机架”转向“让大量 GPU/XPU 在更短距离内高速交换数据”。因此，产业总需求仍可能增长，利润池却未必继续停留在传统可插拔光模块，而可能逐步迁向 NPO、CPO、光 I/O、外置激光器、硅光引擎、先进封装、交换芯片、光纤与连接器。

这不是“传统光模块立即死亡”的判断，而是一个分阶段的价值迁移判断：

- 近期，AI 集群扩张仍推动 800G、1.6T 可插拔光模块放量。
- 中期，当功耗、时延和带宽密度成为更强约束，CPO/NPO/光 I/O 的渗透率可能提高。
- 长期，不能迁移到新架构、封装和系统级能力的传统环节，可能在增长的市场里失去单位链路价值占比。

## 观点的推理链

1. 大模型训练与推理需要更多 GPU/XPU 协同。
2. 计算芯片继续变快时，通信速度不足会造成算力等待。
3. `Scale-up` 比 `Scale-out` 更强调短距离、高带宽密度、低功耗和低时延。
4. 缩短高速电信号路径并把光引擎靠近交换芯片或 XPU，有利于改善这些约束。
5. 集成会减少部分独立 DSP、PCB、模块外壳和传统组装价值，但增加对激光器、硅光、先进封装、精密耦合、光纤和连接器的要求。
6. 因而行业规模增长与单个环节价值占比可能同时朝不同方向变化。

## 支持该观点需要补齐的证据

- NVIDIA 关于 `Scale-up` 与 `Scale-out` 带宽需求的原始发布、演讲或技术文档。
- 各代互连架构的距离、带宽、功耗、时延和每 bit 成本对比。
- 800G、1.6T、NPO、CPO、光 I/O 的出货量、客户导入与收入占比。
- 上述公司的产品目录、客户验证、量产节点、资本开支与管理层指引。
- CPO 架构下 DSP、PCB、模块壳体、激光器、硅光引擎、封装、连接器和组装测试的单位价值变化。

## 反方证据与证伪条件

- `Scale-up` 长期仍主要依靠铜互连或其他方案，光互连渗透明显慢于文章预期。
- CPO 的良率、热管理、维修、标准化或总成本问题长期无法解决。
- 可插拔模块在 1.6T 及更高速率继续改善功耗和密度，延长主流生命周期。
- 外置激光器、硅光或先进封装需求增加，但竞争和降价使利润池没有按预期迁移。
- 被点名公司的技术参与没有转化为可观订单、收入或利润。
- 市场价格已充分甚至过度反映未来增长，基本面兑现仍无法带来合理回报。
